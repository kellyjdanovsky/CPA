Fonctionnalités disponibles
  • Impression : Bouton pour imprimer le tableau complet
  • Export Excel : Téléchargement en format Excel avec toutes les données
  • Export PDF : Génération PDF via DataTables
  • Recherche : Recherche rapide dans toutes les colonnes
  • Tri : Tri par n'importe quelle colonne
  • Pagination : Affichage par 25, 50, 100 ou tous les résultats
Comment accéder au module
  1. Connectez-vous à l'application
  2. Dans le menu latéral, cliquez sur Élèves
  3. Cliquez sur le lien PASCOMA
  4. Le tableau s'affichera avec tous les élèves de l'année scolaire en cours

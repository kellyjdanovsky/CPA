# Guide d'Utilisation - Système de Gestion Scolaire

## Introduction

Bienvenue dans le guide d'utilisation du système de gestion scolaire. Cette application a été conçue pour faciliter la gestion administrative et pédagogique de votre établissement scolaire. Ce guide vous aidera à comprendre et à utiliser efficacement toutes les fonctionnalités disponibles.

## Démarrage

### Accès à l'application

L'application est accessible via un navigateur web à l'adresse fournie par votre administrateur système. Pour une expérience optimale, nous recommandons d'utiliser les navigateurs suivants :
- Google Chrome (version 88 ou supérieure)
- Mozilla Firefox (version 85 ou supérieure)
- Microsoft Edge (version 88 ou supérieure)
- Safari (version 14 ou supérieure)

### Connexion

1. Ouvrez votre navigateur et accédez à l'URL de l'application
2. Sur la page de connexion, entrez vos identifiants (nom d'utilisateur et mot de passe)
3. Cliquez sur le bouton "Se connecter"

## Interface principale

Après la connexion, vous accédez au tableau de bord principal qui présente une vue d'ensemble des informations importantes :

- Statistiques financières récentes
- Calendrier des examens à venir
- Rappels et notifications
- Accès rapide aux modules fréquemment utilisés

La navigation dans l'application se fait via le menu latéral qui permet d'accéder aux différents modules.

## Module Finance

Le module Finance permet de gérer les flux financiers de l'établissement.

### Gestion des encaissements

Pour enregistrer un nouvel encaissement :

1. Accédez au menu "Finance" > "Encaissements"
2. Cliquez sur le bouton "Nouvel encaissement"
3. Remplissez le formulaire avec les informations suivantes :
   - Date
   - Élève concerné
   - Montant
   - Motif (frais de scolarité, frais d'examen, etc.)
   - Mode de paiement
4. Cliquez sur "Enregistrer"

Une fois l'encaissement enregistré, vous pouvez :
- Imprimer un reçu en cliquant sur l'icône d'impression
- Consulter l'historique des encaissements
- Filtrer les encaissements par date, élève ou motif

### Gestion des décaissements

Pour enregistrer un nouveau décaissement :

1. Accédez au menu "Finance" > "Décaissements"
2. Cliquez sur le bouton "Nouveau décaissement"
3. Remplissez le formulaire avec les informations suivantes :
   - Date
   - Bénéficiaire
   - Montant
   - Motif
   - Justificatif (optionnel)
4. Cliquez sur "Enregistrer"

### Synthèse financière

La page de synthèse financière offre une vue d'ensemble des finances de l'établissement :

1. Accédez au menu "Finance" > "Synthèse"
2. Sélectionnez la période souhaitée (jour, semaine, mois, trimestre, année)
3. Consultez les graphiques et tableaux présentant :
   - Total des encaissements et décaissements
   - Solde
   - Répartition par mode de paiement
   - Répartition par motif

Vous pouvez exporter ces données au format Excel ou PDF en utilisant les boutons correspondants.

## Module Matières et Examens

### Gestion des matières

Pour gérer les matières enseignées :

1. Accédez au menu "Matières" > "Liste des matières"
2. Pour ajouter une nouvelle matière, cliquez sur "Nouvelle matière" et remplissez le formulaire :
   - Nom de la matière
   - Abréviation
   - Coefficient
3. Pour modifier une matière existante, cliquez sur l'icône de modification
4. Pour supprimer une matière, cliquez sur l'icône de suppression (attention : cette action est irréversible)

### Configuration des examens

Pour configurer un nouvel examen :

1. Accédez au menu "Examens" > "Liste des examens"
2. Cliquez sur "Nouvel examen"
3. Remplissez le formulaire avec les informations suivantes :
   - Type d'examen (Trimestre 1, Trimestre 2, etc.)
   - Date de début
   - Date de fin
   - Classes concernées
4. Cliquez sur "Enregistrer"

Une fois l'examen créé, vous pouvez :
- Modifier ses paramètres tant qu'il n'est pas verrouillé
- Verrouiller l'examen une fois terminé pour empêcher toute modification des notes

## Module Notes

### Saisie des notes

Pour saisir les notes des élèves :

1. Accédez au menu "Notes" > "Saisie des notes"
2. Sélectionnez l'examen concerné
3. Sélectionnez la classe concernée
4. Un tableau s'affiche avec tous les élèves de la classe et toutes les matières
5. Saisissez les notes pour chaque élève et chaque matière (DS1, DS2, Examen)
6. Cliquez sur "Enregistrer" pour sauvegarder les notes

Le système calcule automatiquement les moyennes en fonction des coefficients des matières.

### Calcul des moyennes

Le calcul des moyennes se fait automatiquement selon la formule suivante :
- Moyenne par matière = (DS1 + DS2 + Examen) / 3
- Moyenne générale = Somme(Moyenne par matière × Coefficient) / Somme(Coefficients)

## Module Bulletins

### Génération des bulletins

Pour générer les bulletins scolaires :

1. Accédez au menu "Bulletins" > "Génération"
2. Sélectionnez l'examen concerné
3. Sélectionnez la classe concernée
4. (Optionnel) Sélectionnez un élève spécifique ou laissez vide pour générer les bulletins de toute la classe
5. Choisissez le format (A4 ou A5)
6. Sélectionnez les options souhaitées :
   - Inclure signature du directeur
   - Inclure graphique de progression
   - Inclure appréciation générale
7. Cliquez sur "Générer PDF"

Une fois les bulletins générés, vous pouvez :
- Prévisualiser chaque bulletin
- Télécharger les bulletins individuellement ou en lot
- Imprimer les bulletins

## Module Archives

### Consultation des archives

Pour consulter les bulletins archivés :

1. Accédez au menu "Archives" > "Bulletins"
2. Utilisez les filtres pour rechercher des bulletins spécifiques :
   - Année scolaire
   - Classe
   - Examen
   - Élève (nom ou matricule)
3. Cliquez sur "Rechercher"
4. Dans la liste des résultats, vous pouvez :
   - Visualiser un bulletin
   - Télécharger un bulletin
   - Imprimer un bulletin

## Module Statistiques

### Analyse des résultats

Pour analyser les résultats scolaires :

1. Accédez au menu "Statistiques" > "Résultats"
2. Sélectionnez l'examen concerné
3. Sélectionnez la classe concernée
4. Consultez les différentes analyses :
   - Moyennes par matière
   - Taux de réussite par matière
   - Évolution des résultats
   - Top 5 des élèves
   - Répartition des moyennes

Vous pouvez exporter ces statistiques au format Excel ou PDF en utilisant les boutons correspondants.

## Astuces et bonnes pratiques

### Sauvegarde régulière

- Enregistrez régulièrement vos saisies, surtout lors de la saisie des notes
- Utilisez la fonction d'export pour sauvegarder des copies externes des données importantes

### Organisation du travail

- Configurez les matières et les examens en début d'année scolaire
- Verrouillez les examens une fois toutes les notes saisies et vérifiées
- Générez et archivez les bulletins dès que possible après la fin des examens

### Résolution des problèmes courants

- Si une page ne se charge pas correctement, essayez de rafraîchir la page
- Si vous rencontrez des erreurs lors de la saisie des notes, vérifiez que l'examen n'est pas verrouillé
- En cas de problème persistant, contactez l'administrateur système
